# 요구사항 — 딴짓 보호 로봇 (가제)

> 무엇을 만들 것인가. 어떻게 연결하는지는 [design.md](design.md), 일정·담당은 [milestones/](milestones/) 를 보세요.

## 한 줄 소개

PC를 쓰는 중 누군가 다가오면 **AI가 감지**해서 **화면을 업무 화면으로 바꾸고**, **로봇이 대신 인사**하는 시스템

## 핵심 흐름

```
웹캠 ─▶ [AI] 사람 감지 ─▶ 감지 신호 ─┬─▶ [로봇] 고개 숙여 인사
                                    ├─▶ [웹]   엑셀 업무 화면으로 전환
                                    └─▶ [앱]   알림 + 감지 기록
```

## 기능과 담당

| 기능 | 담당 | 내용 | 코드 위치 |
|---|---|---|---|
| AI 사람 감지 | 한웅 | 웹캠 실시간 감지 · 일정 시간 이상 인식 시 이벤트 · 사람 존재 여부만 판단 (인물 식별 X) | `src/ai/` |
| 로봇 반응 | 유나 | 라즈봇 카메라 받침대로 인사 · 로봇 얼굴 연출 | `src/robot/` |
| 중앙 서버 | 한웅 | 이벤트 저장, 로봇에 인사 명령, 상태·기록 제공 | `src/server/` |
| 웹 화면 전환 | 채웅 | 감지 시 가상 엑셀 화면 전환, 사라지면 복귀 · 웹 대시보드 | `src/web/` |
| 앱 기록 관리 · 발표 | 채연 | 감지 알림 · 시간·횟수 기록 · 일별 이력 · 일정 관리 · 발표자료 총괄 | `src/app/` |

## 요구 명세 (수용 기준)

| ID | 요구 | 수용 기준 |
|---|---|---|
| REQ-01 | 사람 감지 → 화면 전환 | 사람이 2초 이상 보이면 `person_detected`, 3초 이상 안 보이면 `person_left` (각 1회만). 웹 화면은 0.5초마다 상태를 확인해 엑셀 화면 ↔ 원래 화면 전환 |
| REQ-02 | 감지 이력 | 앱이 날짜별 감지 시각 목록과 횟수를 보여주고, 새 감지가 생기면 알림 (2초마다 확인) |
| REQ-03 | 로봇 인사 | `POST /greet` 를 받으면 받침대를 숙였다 원위치, `{"ok": true}` 응답. 인사 중 요청은 무시 (쿨다운 10초) |
| REQ-04 | 부분 실패 | 로봇이 꺼져 있어도 (응답 2초 초과) 서버·웹·앱은 정상 동작. 기록이 없는 날은 "기록 없음" 표시 |

우선순위: REQ-01 > REQ-03 > REQ-02 > REQ-04

## 범위

**필수**: 위 REQ-01~04 + 기능 간 신호 연동

**여유 있으면**: 로봇 외형 꾸미기 · 감지 사진 저장 · 로봇 추가 동작

**제외**: 특정 인물 식별, 로봇 바퀴 이동·자율주행, 인터넷 원격 연동

## 시연 시나리오

1. 팀원이 노트북으로 영상 시청
2. 다른 팀원이 카메라 쪽으로 접근 → AI 감지
3. 웹 화면이 엑셀 업무 화면으로 전환
4. 라즈봇이 고개 숙여 인사
5. 사람이 사라지면 원래 화면 복귀
6. 앱에서 감지 기록·횟수 확인

## 진행 원칙

- 기간이 짧고 입문자가 많으니 **기존 라이브러리·예제 최대한 활용**
- 각자 기능 먼저 구현 → 통합. 하드웨어 없는 팀원은 **테스트용 데이터**(`data/`)로 개발
- 통합 테스트 이후엔 기능 추가보다 **오류 수정·시연 안정성** 우선
