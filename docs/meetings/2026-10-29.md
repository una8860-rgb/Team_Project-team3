## 1. 프로젝트 주제: 딴짓 보호 로봇 (가제)

- **프로젝트명**: 추후 팀원 의견을 모아 최종 명칭 선정
- **목표**: AI 기반 사람 감지 및 로봇 자동 반응 시스템 구현
- **개념**: PC 사용 중 주변에 사람이 접근하면 AI가 감지하여 PC 화면을 업무 화면으로 자동 전환하고, 로봇이 대신 인사하는 시스템

### 주요 기능

1. **AI 사람 감지**
   - 웹캠으로 주변 사람 존재 여부를 실시간 감지
   - 일정 시간 이상 사람이 인식되면 이벤트 발생
   - 특정 인물을 식별하지 않고 사람의 존재 여부만 판단
2. **로봇 자동 반응**
   - 감지 신호를 받으면 라즈봇 카메라 받침대를 움직여 고개 숙여 인사
   - 사전 녹음한 음성으로 인사
   - 로봇 얼굴 부착 등 시각적 연출
3. **웹 화면 자동 전환**
   - 평상시 일반 웹 화면 → 사람 감지 시 가상의 엑셀 업무 화면으로 전환
   - 사람이 사라지면 기존 화면으로 복귀
4. **앱 알림 및 기록 관리**
   - 감지 시 알림 표시
   - 감지 발생 시간·횟수 기록, 일별 감지 이력 확인

### 시연 시나리오

1. 팀원이 노트북으로 영상을 시청하는 상황 연출
2. 다른 팀원이 카메라 방향으로 접근
3. AI가 사람을 감지하고 이벤트 발생
4. 웹 화면이 가상의 엑셀 업무 화면으로 전환
5. 라즈봇이 고개를 숙이며 "안녕하십니까 팀장님!" 음성 출력
6. 사람이 사라지면 기존 화면으로 복귀
7. 앱에서 감지 기록 및 횟수 확인

> ※ 로봇 바퀴 이동은 필수 기능에서 제외. 카메라 받침대 회전을 활용한 인사 동작 중심으로 구현
