## 실행 방법

레포 맨 위 폴더에서:

```
pip install streamlit==1.50.0 requests==2.32.3
streamlit run src/app/app.py
```

실제 서버에 연결할 때 (PowerShell):

```
$env:SERVER_HOST="<서버 IP>"; streamlit run src/app/app.py
```
