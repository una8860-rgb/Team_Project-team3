# M3. 웹 화면 전환·대시보드 (담당: 채웅)

- **목표**: 감지 상태에 따라 일반 화면 ↔ 가상 엑셀 업무 화면으로 전환하는 웹 페이지 (REQ-01)
- **코드**: `src/web/` · **규격**: `docs/design.md` ③ · **샘플 데이터**: `data/sample_status.json`
- **서버**: 한웅이 만드는 중앙 서버(`src/server/`)에 `GET /api/status` 로 연결
- **기한**: 11/1 단독 시험 완료 → 11/2 통합

## 할 일
- [x] 일반 화면 (영상 시청 등) 만들기
- [x] 가상 엑셀 업무 화면 만들기
- [x] 0.5초마다 `GET /api/status` 확인 → `present` 면 엑셀 화면, `absent` 면 원래 화면
- [x] 서버 없이 테스트 모드(버튼으로 상태 변경)로 전환 동작 확인
- [ ] 한웅 서버와 붙이는 방식 정하기 (서버가 `src/web` 을 띄워 주기 또는 CORS 허용)
- [x] (여유 있으면) 감지 기록을 보여주는 웹 대시보드 (`src/web/dashboard.html`)

## 완료 기준
- 상태가 `present` 가 되면 1초 안에 엑셀 화면으로, `absent` 가 되면 원래 화면으로 돌아감
