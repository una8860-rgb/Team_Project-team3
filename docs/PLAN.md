# 📋 프로젝트 기획서 — 딴짓 보호 로봇 (가제)

> PC를 쓰는 중 누군가 다가오면 **AI가 감지**해서 **화면을 업무 화면으로 바꾸고**, **로봇이 대신 인사**하는 시스템

## 핵심 흐름

```
웹캠 ─▶ [AI] 사람 감지 ─▶ 감지 신호 ─┬─▶ [로봇] 고개 숙여 인사 + 음성
                                    ├─▶ [웹]   엑셀 업무 화면으로 전환
                                    └─▶ [앱]   알림 + 감지 기록
```

## 기능 (담당)

| 기능 | 담당 | 내용 |
|---|---|---|
| 🧠 AI 사람 감지 | 한웅 | 웹캠 실시간 감지 · 일정 시간 이상 인식 시 이벤트 · 사람 존재 여부만 판단 (인물 식별 X) |
| 🦾 로봇 반응 | 유나 | 라즈봇 카메라 받침대로 인사 · 녹음 음성 출력 · 로봇 얼굴 연출 |
| 🌐 웹 화면 전환 | 채웅 | 백엔드·서버 · 감지 시 가상 엑셀 화면 전환, 사라지면 복귀 · 웹 대시보드 |
| 📱 앱 기록 관리 · 발표 | 채연 | 감지 알림 · 시간·횟수 기록 · 일별 이력 · 일정 관리 · 발표자료 총괄 |

## 필수 기능
- [ ] AI 사람 감지
- [ ] 라즈봇 고개 숙여 인사
- [ ] 웹 화면 자동 전환
- [ ] 앱 감지 기록 표시
- [ ] 기능 간 신호 연동

**여유 있으면**: 인사 음성 다양화 · 로봇 외형 꾸미기 · 감지 사진 저장 · 로봇 추가 동작

## 시연 시나리오
1. 팀원이 노트북으로 영상 시청
2. 다른 팀원이 카메라 쪽으로 접근 → AI 감지
3. 웹 화면이 엑셀 업무 화면으로 전환
4. 라즈봇이 고개 숙이며 "안녕하십니까 팀장님!"
5. 사람이 사라지면 원래 화면 복귀
6. 앱에서 감지 기록·횟수 확인

## 진행 원칙
- 기간이 짧고 입문자가 많으니 **기존 라이브러리·예제 최대한 활용**, 자율주행·바퀴 이동은 제외
- 각자 기능 먼저 구현 → 통합. 하드웨어 없는 팀원은 **테스트용 데이터**로 개발
- 통합 테스트 이후엔 기능 추가보다 **오류 수정·시연 안정성** 우선
