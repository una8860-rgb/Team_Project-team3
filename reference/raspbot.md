# 라즈봇 정보

> 실물을 확인하면서 채웁니다. 모르는 칸은 "미확인"으로 둡니다.

| 항목 | 내용 |
|---|---|
| 모델명 | Yahboom Raspbot V2 (아이씨뱅큐 판매, 교육용) |
| 제품 설명 링크 | [Yahboom Raspbot V2 드라이버 설치](https://www.yahboom.net/public/upload/upload-html/1725440947/7.%20Install%20Raspbot%20V2%20driver%20library.html) |
| 컴퓨터 | 라즈베리파이 5 / Debian 13 (trixie) / Python 3.13 |
| 확장보드 | I2C 버스 1, 주소 `0x2B` (`0x3C` 는 OLED 화면) — I2C 는 `raspi-config` 로 켜야 함 |
| 카메라 받침대 서보 | 보드 **S1 = 상하**, **S2 = 좌우** (선을 다시 꽂으면 바뀔 수 있음) |
| 서보 각도 (10/30 확인) | 상하: 평소 **30도**(정면), 인사 **0도**(숙임), 숫자 작을수록 아래 / 좌우: 정면 **80도**, 숫자 작을수록 왼쪽 |
| 서보 제어 방법 | 레지스터 `0x02` 에 `[서보번호, 각도]` 쓰기 (제조사 Raspbot_Lib `Ctrl_Servo` 와 같음). 키트 앱·라이브러리 설치 필요 없음 |
| 그 밖에 확인된 것 | 부저: 레지스터 `0x06` `[1]` 켬 / `[0]` 끔. 모터: 레지스터 `0x01` `[모터번호, 방향, 속도]` (0번 = 앞왼쪽) |
| 스피커 | 없음 (HDMI 출력만 있음) → USB·블루투스 스피커 필요, 미정 |
| 전원 | 본체 배터리 + 전원 스위치. 서보·모터는 배터리 전원으로 움직임 |
| 설치한 프로그램 | `python3-flask`, `python3-smbus`, `i2c-tools`, `mpg123` (apt) |
