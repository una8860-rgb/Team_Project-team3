# src/app — 앱 (담당: 채연)

감지 알림과 날짜별 감지 기록·횟수를 보여주는 앱입니다.

- 규격: `docs/design.md` ④ · 진행 상황·인수인계: `docs/milestones/M4-app.md`

## 1. 무엇을 하는 프로젝트인지

**딴짓 보호 로봇**: 웹캠 AI가 사람이 다가오는 것을 감지하면
- 웹 화면이 엑셀 업무 화면으로 바뀌고
- 라즈봇이 고개 숙여 인사하고
- **앱에 감지 기록이 남는** 시스템입니다.

앱은 이 중 **"언제, 몇 번 사람이 왔는지"를 알려 주고 기록을 보여주는 부분**을 맡습니다.

## 2. 각 부분이 어떤 역할을 하는지

| 부분 | 담당 | 역할 |
|---|---|---|
| AI 사람 감지 (`src/ai/`) | 한웅 | 웹캠으로 사람을 감지해서 서버에 알림 |
| 중앙 서버 (`src/server/`) | 한웅 | 감지 기록 저장, 로봇에 인사 명령, 웹·앱에 정보 제공 |
| 로봇 (`src/robot/`) | 유나 | 서버 명령을 받으면 고개 숙여 인사 |
| 웹 화면 (`src/web/`) | 채웅 | 사람이 오면 엑셀 화면으로 전환 |
| **앱 (`src/app/`)** | **채연** | **새 감지 알림 + 날짜별 감지 기록·횟수 표시** |

앱은 서버에 **물어보기만** 합니다. AI나 로봇과 직접 연결하지 않습니다.

## 3. 어떤 기능을 포함하는지

앱 이름은 **언더커버**입니다. 평소에는 솔직하게 상태를 보여주고, "위장 모드"를 켜면 평범한 업무 캘린더처럼 보입니다. 화면 설계와 시안: [`SCREEN.md`](SCREEN.md)

- **지금 상태**: 홈의 상태 카드 "지금 아무도 없어요" / "누가 왔어요!"
- **새 감지 알림**: 2초마다 서버에 기록을 물어보고, 새 `person_detected` 가 있으면 알림
- **방문 기록**: 나타남과 사라짐을 묶어 방문 한 건으로 표시, 머문 시간 계산
- **날짜별 기록**: 주간 날짜 줄과 한 달 달력에서 날짜를 눌러 그날 기록 보기
- **위장 모드**: 버튼 하나로 캘린더 화면으로 전환 ("집중 시간" = 아무도 없음, "회의 시작" = 누가 옴)
- **기록 없음 표시**: 기록이 없는 날은 "이날은 방문 기록이 없어요"
- **테스트 모드**: 서버가 없으면 `data/sample_events.json` 을 오늘 날짜로 바꿔 보여주고, 기록 탭 아래 테스트 버튼으로 감지를 흉내 냄

## 실행 방법

레포 맨 위 폴더에서 실행합니다.

```
pip install -r requirements.txt
streamlit run src/app/app.py
```

- 브라우저가 열리고 대시보드가 보입니다. 휴대폰은 같은 Wi-Fi에서 터미널에 나오는 `Network URL` 주소로 접속합니다.
- 서버가 없으면 자동으로 샘플 데이터를 보여줍니다. 기록 탭 맨 아래 "가짜 왔어요", "가짜 갔어요" 버튼으로 알림과 상태 변화를 시험할 수 있습니다. (서버에 연결되면 버튼이 사라집니다)
- 11/2 실제 서버에 연결할 때 (PowerShell, 서버 IP는 한웅이 공유):

```
$env:SERVER_HOST="192.168.0.10"; streamlit run src/app/app.py
```

## 5. 예시는 어떤 것이 있는지

**서버에 보내는 요청** (`2026-11-02` 기록 가져오기)
```
GET /api/events?date=2026-11-02
GET /api/stats?date=2026-11-02
```

**서버가 주는 응답** (`data/sample_events.json` 의 앞부분. 전체는 4개)
```json
[
  { "id": 1, "type": "person_detected", "timestamp": "2026-11-02T14:03:21+09:00", "confidence": 0.87 },
  { "id": 2, "type": "person_left",     "timestamp": "2026-11-02T14:03:40+09:00", "confidence": null }
]
```
```json
{ "date": "2026-11-02", "count": 2 }
```

**앱 화면 예시** (위 응답을 받았을 때)
```
[솔직 모드 홈]                     [위장 모드 홈]
지금 아무도 없어요                  11월 2일 (월)
23분째 조용해요                     14:00  14:03 잠깐 미팅 · 19초
오늘 방문 2회 | 마지막 14:10               14:10 잠깐 미팅 · 26초
최근 기록                           지금 14:33 ──────────
 누가 왔다 갔어요  14:10:05 ~ 14:10:31  26초    집중 시간
 누가 왔다 갔어요  14:03:21 ~ 14:03:40  19초    14:10부터
```
실제 화면 모양은 [`SCREEN.md`](SCREEN.md) 의 시안 이미지를 보세요.

## 6. 프로젝트 전반의 흐름

```
1. 사람이 다가옴
2. AI가 2초 이상 보이면 → 서버에 "person_detected" 보냄
3. 서버가 기록 저장 → 로봇에 인사 명령
4. 웹 화면은 0.5초마다 서버에 물어봄 → 엑셀 화면으로 전환
5. 앱은 2초마다 서버에 물어봄 → 새 감지가 있으면 알림, 목록·횟수 갱신
6. 사람이 3초 이상 안 보이면 → AI가 "person_left" 보냄 → 앱 목록에 "사라짐" 추가
```

앱에서 새 알림을 판단하는 방법: 마지막으로 본 `id` 보다 큰 `person_detected` 가 생기면 알림을 띄웁니다.
