# src/robot — 라즈봇 인사 서버 (담당: 유나)

라즈봇에서 돌아가는 작은 서버입니다. 중앙 서버가 인사 명령을 보내면 카메라 받침대를 숙였다 올립니다. 인사 음성은 없습니다 (10/31 결정).

- 받는 것: `POST /greet`, `GET /health` (포트 5000). 규격은 `docs/design.md` ②
- 한 번 인사하면 10초 동안은 다시 인사하지 않습니다 (쿨다운)
- 장치 정보·각도·고장 기록: `reference/raspbot.md` / 마일스톤: `docs/milestones/M2-robot-greet.md`

## 1. 켜기

1. 라즈봇 본체 전원 스위치를 켭니다.
2. 1분쯤 기다립니다. 켜지는 동안 고개가 옆으로 한 번 튀었다가 정면으로 돌아옵니다.
3. 고개가 정면을 보면 준비 끝입니다. 인사 서버는 저절로 실행됩니다. 노트북으로 접속할 필요가 없습니다.

라즈봇은 미리 등록한 와이파이에만 붙습니다. 노트북과 같은 와이파이(11/2에는 팀 핫스팟)에 있어야 합니다.

## 2. 라즈봇 IP

중앙 서버(한웅)가 라즈봇에 명령을 보내려면 라즈봇 IP가 필요합니다. IP는 와이파이마다 바뀝니다.

- 11/2 당일 핫스팟에서 확인해서 단톡에 공유합니다.
- 중앙 서버를 켤 때 그 IP를 넣습니다. (PowerShell)
  ```
  $env:ROBOT_HOST="<라즈봇IP>"; python src/server/server.py
  ```

## 3. 인사가 되는지 확인

노트북에서 실행합니다. Windows PowerShell 에서는 `curl` 이 아니라 `curl.exe` 로 써야 합니다.

연결 확인:
```
curl.exe http://<라즈봇IP>:5000/health
```

인사 시키기:
```
curl.exe -X POST http://<라즈봇IP>:5000/greet
```

| 응답 | 뜻 |
|---|---|
| `{"ok":true}` | 인사함 |
| `{"ok":true,"skipped":"cooldown"}` | 명령은 받았지만 마지막 인사 후 10초가 안 지나서 건너뜀. 오류 아님 |
| 응답 없음 (시간 초과) | 라즈봇이 꺼져 있거나 다른 와이파이에 있음. 아래 문제 해결 참고 |

## 4. 끄기

전원 스위치를 바로 끄면 SD카드가 망가질 수 있습니다. 파이를 먼저 종료합니다.

1. 유나 노트북에서 실행: `ssh -t pi "sudo shutdown -h now"` (파이 비밀번호 입력)
2. 파이의 초록불이 멈추고 빨간불만 남을 때까지 10~20초 기다립니다.
3. 전원 스위치를 끕니다.

유나 노트북이 없으면, 시연이 다 끝난 뒤 초록불이 깜빡이지 않을 때 스위치를 끕니다.

## 5. 문제 해결

| 증상 | 할 일 |
|---|---|
| 켠 뒤 고개가 옆을 보고 있음 | 10초 더 기다립니다. 서버가 정면을 한 번 더 맞춥니다 |
| 인사 후 고개가 정면이 아님 | 다시 인사시키면 끝에 정면으로 돌아옵니다. 계속 틀어지면 유나에게 (각도 조정) |
| `/health` 응답 없음 | 라즈봇 전원, 같은 와이파이인지, IP가 맞는지 확인. 켠 지 1분이 안 됐으면 기다립니다 |
| 응답은 `{"ok":true}` 인데 고개가 안 움직임 | 전원 스위치가 켜져 있는지(서보는 배터리 전원으로 움직임), 배터리 충전, 서보 선이 보드 S1·S2 핀에 끝까지 꽂혀 있는지 확인 |
| 계속 `skipped` 만 옴 | 정상입니다. 10초 기다렸다가 다시 보냅니다 |

## 6. 개발자용

로봇 없이 테스트 모드로 실행 (서보 대신 콘솔에 출력, 아무 컴퓨터에서나 가능):
```
pip install -r requirements.txt
python src/robot/robot_server.py --mock
```
다른 PowerShell 창에서 `curl.exe -X POST http://127.0.0.1:5000/greet` 로 확인합니다.

각도 바꾸기: `robot_server.py` 맨 위 상수
- `BASE_ANGLE` 평소 상하 각도 (30), `BOW_ANGLE` 인사 각도 (0), `PAN_CENTER` 좌우 정면 (78)
- 상하는 숫자가 작을수록 아래, 좌우는 숫자가 작을수록 오른쪽 (로봇 뒤에서 볼 때)

라즈봇에 바뀐 코드 넣기 (유나 노트북, 레포 맨 위 폴더에서):
```
scp -r src/common src/robot pi:~/team3/src/
ssh -t pi "sudo systemctl restart robot-greet"
```

라즈봇 쪽 설정:
- 코드 위치: `~/team3/src/`
- 자동 실행: systemd 서비스 `robot-greet` (멈추면 3초 뒤 다시 켜짐)
- 로그 보기: `ssh pi "journalctl -u robot-greet -n 30"`
- 필요한 프로그램 (apt): `python3-flask`, `python3-smbus`, `i2c-tools`. I2C 켜기: `sudo raspi-config nonint do_i2c 0`
