# src/web — 웹 화면 (담당: 채웅)

평소엔 영상 화면, 사람이 감지되면 가짜 엑셀 업무 화면으로 바뀌는 웹 페이지입니다.

- 0.5초마다 `GET /api/status` 확인 → `present` 면 엑셀 화면, `absent` 면 원래 화면
- 평소 화면은 실제 유튜브 영상. 엑셀로 바뀌면 일시정지, 돌아오면 다시 재생
- 엑셀 화면은 엑셀 웹 모양으로 만든 가짜 화면 (리본 메뉴, 수식 입력줄, 셀 격자, 시트 탭, 상태 표시줄). 인터넷 없이 바로 뜸
- 셀에 직접 입력·수정 가능. 클릭으로 선택, 바로 입력하면 덮어쓰기, 더블클릭이나 F2 는 이어서 수정
  - Enter 아래 칸, Tab 오른쪽 칸, 화살표 이동, Esc 취소, Delete 지우기
  - 여러 칸 선택: 마우스로 끌기, Shift+클릭, Shift+화살표. 상태 표시줄에 평균·개수·합계 표시
  - 숫자를 바꾸면 합계·달성률이 다시 계산됨. `=SUM(C5:E5)`, `=AVERAGE(...)`, `=MAX(...)`, `=MIN(...)`, `=F5/G5` 같은 수식 입력 가능
- 리본 메뉴 (동작함): 실행 취소/다시 실행, 잘라내기/복사/붙여넣기, 서식 복사, 글꼴, 글꼴 크기, 굵게/기울임/밑줄/취소선,
  테두리, 채우기 색, 글꼴 색, 위·가운데·아래 맞춤, 왼쪽·가운데·오른쪽 맞춤, 들여쓰기, 텍스트 줄 바꿈,
  병합하고 가운데 맞춤(가운데 맞춤만 함), 표시 형식(일반/숫자/통화/백분율/텍스트), 통화·%·쉼표, 소수 자릿수, 자동 합계, 서식 지우기
- 리본 메뉴 (모양만): 조건부 서식, 테이블로 서식 지정, 셀 스타일, 삽입·삭제·서식, 정렬 및 필터, 찾기 및 선택, 추가 기능
- 단축키: Ctrl+Z/Y/X/C/V/B/I/U
- 유튜브를 못 불러오면(인터넷 없음, 영상 오류) 가짜 영상 화면으로 바꿈
- 브라우저 탭 제목·아이콘도 같이 바뀜 (`YouTube` ↔ `2026_4분기_매출보고서.xlsx - Excel`)
- 서버 응답이 없으면 화면은 그대로 두고 오른쪽 아래에 "서버 연결 끊김" 표시
- 규격: `docs/design.md` 3번 / 마일스톤: `docs/milestones/M3-web.md`

## 시작 버튼

브라우저는 사용자가 한 번 클릭해야 전체 화면 전환과 소리 있는 영상 재생을 허락합니다.
그래서 페이지를 열면 "시작" 버튼을 한 번 누릅니다. 누르면 전체 화면으로 바뀌고 영상이 재생됩니다.
새로고침하면 다시 눌러야 합니다. 전체 화면은 Esc 로 나갑니다.

## 영상 바꾸기

시작 화면의 입력칸에 유튜브 영상 주소를 붙여 넣으면 그 영상으로 바뀝니다.
`youtube.com/watch?v=...`, `youtu.be/...`, 쇼츠 주소 모두 됩니다. 고른 영상은 브라우저가 기억해서 다음에 열어도 그대로 나옵니다.

- 처음 띄울 영상 순서: 주소 뒤 `?video=유튜브주소` → 지난번에 고른 영상 → `config.js` 의 `DEFAULT_VIDEO_URL`
- 주소에 `&t=19s` 같은 시작 시간이 있으면 그 시간부터 재생합니다.
- 퍼가기를 막아 둔 영상은 재생되지 않고 가짜 영상 화면으로 바뀝니다. 그때는 새로고침 후 다른 영상을 고릅니다.

## 대시보드

감지 기록을 보는 페이지입니다. `dashboard.html` 을 엽니다.

- 2초마다 `GET /api/events?date=`, `GET /api/stats?date=`, `GET /api/status` 를 받습니다. (규격 3, 4번)
- 숫자 카드: 감지 횟수, 현재 상태, 마지막 감지, 평균 머문 시간
- 오늘의 타임라인: 하루(0~24시) 가로 띠에 사람이 있던 구간을 칠함. 머무는 중이면 지금 시각까지 깜빡이며 표시
  - 아래 요약 한 줄: 가장 많이 온 시간대, 가장 오래 머문 시간, 총 머문 시간, 평균 신뢰도
- 시간대별 감지 횟수: 기록이 있는 시간대에만 막대, 막대 위에 횟수, 마우스를 올리면 막대 강조와 툴팁
- 최근 7일: 막대 뒤에 흐름 곡선과 옅은 면적, 오늘 막대만 진한 색과 큰 숫자로 강조 (15초마다 다시 받음)
- 새 감지 알림: 사람이 감지되면 오른쪽 위에 5초 동안 알림 (최대 3개)
- 기록 표: 최신순, 10줄씩 페이지로 나눔(아래 1 2 3 번호), 필터(전체/감지만/사라짐만), 엑셀로 내보내기(CSV, 엑셀에서 한글 안 깨짐)
- 기록 표 뱃지: 사람 감지(주황, 사람 아이콘) / 사람 사라짐(초록, 나가는 화살표) / 머무는 중(퍼지는 점). 신뢰도는 숫자 + 작은 막대
- 화면 폭에 따라 배치가 바뀝니다: 넓은 화면 숫자 카드 4칸, 1080px 이하 2칸(그래프 위아래), 520px 이하 1칸. 표는 좁으면 가로로 밀어서 봅니다.
- 상단 바 버튼: 크게 보기(발표용, 표를 숨기고 카드·그래프를 크게, 전체 화면, Esc 로 나감), 다크 모드(선택을 기억)
- 날짜를 바꾸면 그날 기록을 보여줍니다.
- 테스트 모드(`?test=1`): 서버 대신 `data/sample_events.json` 을 씁니다.
- 서버 응답이 없으면 마지막 화면을 두고 "서버 연결 끊김" 을 표시합니다.

열기: http://localhost:8080/src/web/dashboard.html?test=1 (서버 없이) /
`http://<서버 IP>:8000/dashboard.html` 또는 `dashboard.html?server=http://<서버 IP>:8000` (서버 연결)

## 실행

서버 없이 테스트 (버튼 또는 키보드 `Alt+1` 감지, `Alt+2` 사라짐):

- 레포 최상위에서 `python -m http.server 8080` → http://localhost:8080/src/web/?test=1
- `src/web/index.html` 을 더블클릭해서 열어도 되지만, 이때는 유튜브가 막혀서 가짜 영상 화면이 나옵니다.
- 유튜브 영상을 클릭한 뒤에는 키보드 입력이 영상으로 가서 단축키가 안 먹습니다. 왼쪽 아래 버튼을 쓰세요.

중앙 서버(한웅)에 붙일 때 방법은 둘 중 하나입니다.

1. 서버가 `src/web` 폴더를 같이 띄워 주는 경우: 서버 주소로 열면 끝 (예: `http://<서버 IP>:8000/`). 설정 필요 없음.
2. 웹 화면을 따로 여는 경우: 주소 뒤에 `?server=http://<서버 IP>:8000` 을 붙여 엽니다.
   이때 서버가 다른 주소에서 오는 요청을 허용해야 합니다 (CORS, `Access-Control-Allow-Origin: *`).
